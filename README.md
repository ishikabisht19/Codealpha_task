🎓 Student Grade Tracker

A simple console-based Java application that helps users manage student grades and generate summary reports.

📌 About the Project

The Student Grade Tracker is a beginner-friendly Java project developed to manage student names and their subject marks. It calculates the average, highest, and lowest scores for each student and displays the results in a summary report.

This project demonstrates fundamental Java programming concepts and basic data structure usage.

✨ Features

- ➕ Add student names and subject marks
- 📊 Calculate average marks
- 🏆 Find the highest score
- 📉 Find the lowest score
- 📋 Display a summary report of all students
- ✅ Validate marks between 0 and 100
- 🖥️ Simple menu-driven console interface

🛠️ Technologies Used

- Language: Java
- Data Structure: ArrayList
- Input Handling: Scanner
- Concepts: Classes, Objects, Methods, Loops, Conditional Statements

⚙️ How to Run the Project

Step 1: Install Java

Install the Java Development Kit (JDK) on your computer.

Step 2: Clone the Repository

git clone https://github.com/YOUR-USERNAME/Student-Grade-Tracker.git

Replace "YOUR-USERNAME" with your GitHub username.

Step 3: Open the Project Folder

cd Student-Grade-Tracker

Step 4: Compile the Java Program

javac StudentGradeTracker.java

Step 5: Run the Program

java StudentGradeTracker

🧮 Calculations

Average Score

Average = Sum of all subject marks / Number of subjects

Highest Score

The maximum mark among all subject grades.

Lowest Score

The minimum mark among all subject grades.

Example

Subject| Marks
Mathematics| 80
Java| 90
DBMS| 70

- Average: 80.00
- Highest: 90.00
- Lowest: 70.00
